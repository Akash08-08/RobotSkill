# Week 1 Scripts

Bash scripts written during Week 1 of my robotics learning journey.

## Scripts

- `my_first_script.sh` — first ever bash script, variables practice
- `check_folder.sh` — if statement practice
- `new_day.sh` — creates a daily notes file automatically
- `loops.sh` — for loop practice
- `while_loop.sh` — while loop practice
- `functions.sh` — functions practice
- `setup_week.sh` — sets up weekly folder structure automatically
- `progress_tracker.sh` — tracks daily learning progress and streak

## Usage

Log a day:
./progress_tracker.sh log 6 "what you learned"

Show summary:
./progress_tracker.sh summary

Show streak:
./progress_tracker.sh streak
